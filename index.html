#敏感目录

#git泄露

Git是一个开源的分布式版本控制系统，在执行git init初始化目录的时候，会在当前目录下自动创建一个.git目录，用来记录代码的变更记录等。发布代码的时候，如果没有把.git这个目录删除，就直接发布到了服务器上，攻击者就可以通过它来恢复源代码。
● 常规git泄露
（1）url+/.git/访问。
（2）或者使用scrabble或者其他工具读出源码即可
./scrabble http://example.com/
● git回滚
（1）git会记录每次的提交的修改，在比赛中拿到的flag文件有可能是被删除或者覆盖过的，这时可以利用git reset –hard HEAD^来恢复到以前的版本
（2）也可以用git log –stat查看commit修改了哪些文件，再用git diff HEAD commit-id
● git分支
（1）每次提交git都会将她们串为一条时间线，这条时间线就是一条分支，git允许有多条分支，则需要的flag文件有可能不在主分支即master上，而 git log只能看到当前分支的。
（2）对于获取其他的分支、tag，都可以从/.git/refs/heads、/.git/refs/tag里面拿到最新的commit对象id，然后就是顺着这个可以爬到parent commit
（3）假设获取master，最新的commit的object id可以在/.git/refs/heads/master获取到
● 其他利用方式
（1）从.git/config可能有access_token信息， 从而访问这个用户的其他的仓库
（2）在访问.git的时候有可能会返回403，此时可以试着访问.git/config，若有文件返回则有可能存在泄露。
（3）漏洞利用工具：GitHack
用法示例：GitHack.py http://www.openssl.org/.git/

【陇剑杯 2023】IR 应急响应分析

附件是ova形式的文件，OVA 文件是虚拟环境的 “完整快照”，包含了虚拟机的所有数据痕迹，是数字取证中重要的分析载体。通过解析其虚拟磁盘和配置文件，可还原用户操作、系统活动及潜在的恶意行为，为案件调查提供关键证据。

OVA 文件的取证核心是对其包含的虚拟磁盘文件（如.vmdk）和配置文件（.ovf）进行解析，提取与案件相关的证据。
